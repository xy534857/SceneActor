Programmatic access

API 使用说明

团队白名单网络内直接调用，无需鉴权。Base URL 为当前地址。

POST/v1/productions · 编译场景
curl -X POST /v1/productions \
-H 'Content-Type: application/json' \
-d '{"material":"场景与人物……","models":{"compile":"claude-opus-4.8"}}'
POST/v1/performances · 提交演出
curl -X POST /v1/performances \
-H 'Content-Type: application/json' \
-d '{"production_id":"prod:xxx","review":true}'
GET/v1/personas · 人物库
curl /v1/personas
curl /v1/personas/sam-altman
POST/v1/chats · 对话

用 person_id 选库内人物，或把完整人物包放在 record。search 开启联网分诊。

curl -X POST /v1/chats \
-H 'Content-Type: application/json' \
-d '{"person_id":"sam-altman","model":"claude-fable-5","search":true}'

curl -X POST /v1/chats/chat%3Axxx \
-H 'Content-Type: application/json' -d '{"message":"你怎么看最近的发布？"}'
